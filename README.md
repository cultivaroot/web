# CultivaRoot Web

The public, multilingual website for CultivaRoot: an open-source ecosystem for connected cultivation environments.

## Languages

- English (`/`)
- French (`/fr/`)
- Chinese (`/zh/`)

## Focus

CultivaRoot integrates with Home Assistant to help growers observe and adjust environmental conditions, including temperature, humidity, nutrient solution temperature, pH, EC, and lighting.

## Development

```bash
pnpm install
pnpm dev
```

Create a production build with `pnpm build`. The site is intended for deployment to Cloudflare Workers as `cultivaroot-web`.
